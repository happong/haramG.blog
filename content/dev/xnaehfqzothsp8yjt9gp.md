오늘은 while문에 대해 다뤄보려 해요. 지난 글들에서 for문으로 "정해진 횟수만큼 반복"하고, break와 continue로 반복을 멈추고 건너뛰는 걸 배웠다면, 오늘 배울 while문은 "조건이 맞는 동안 계속 반복"하는 방법이에요! 마지막에 퀴즈도 있으니 끝까지 함께 풀어봐요.

while문이란?

while문은 "조건이 True인 동안 계속 반복해라"는 명령이에요.

게임 PM 업무로 비유하면, "빌드가 성공할 때까지 계속 다시 돌려라"와 비슷해요. 몇 번 만에 성공할지 미리 알 수 없을 때는 for문보다 while문이 잘 어울려요.

count = 1
while count <= 3:
    print(count, "번째 빌드 시도")
    count += 1
#결과
1 번째 빌드 시도
2 번째 빌드 시도
3 번째 빌드 시도

while 뒤의 조건(count <= 3)이 True인 동안 들여쓴 코드를 반복하고, 조건이 False가 되는 순간 반복을 멈춰요.

for문 vs while문

똑같이 1부터 3까지 출력하는 코드를 두 가지로 써보면 이렇게 돼요.

for i in range(1, 4):
    print(i)

i = 1
while i <= 3:
    print(i)
    i += 1
#결과 (둘 다 같아요)
1
2
3

for문은 반복할 범위를 처음에 정해두고, while문은 매번 조건을 확인하면서 반복해요.
- 몇 번 반복할지 알 때 → for문
- 언제 끝날지 모를 때 → while문

중요한 점 하나! 조건이 언젠가는 False가 되도록 해야 해요

while문에서 가장 많이 하는 실수는 조건을 바꾸는 코드를 빼먹는 거예요.

count = 1
while count <= 3:
    print(count, "번째 빌드 시도")
#count += 1 을 빼먹으면?

count가 계속 1이라서 조건이 영원히 True예요. 그래서 반복이 끝나지 않는 "무한 루프"가 돼요.
혹시 무한 루프에 빠졌다면 Ctrl + C를 눌러서 멈출 수 있어요. 이 부분 꼭 기억해주세요!

콜론(:)과 들여쓰기도 마찬가지예요

if문, for문에서 배웠던 것처럼 while문도 첫 줄 끝에 콜론(:)을 붙이고, 반복할 코드는 들여쓰기해야 해요.

실무에서 이렇게 쓰여요

빌드가 실패하면 다시 시도하되, 최대 3번까지만 시도하는 코드예요.

retry = 0
build_ok = False
while not build_ok and retry < 3:
    retry += 1
    print(retry, "번째 빌드 시도")
    if retry == 3:
        build_ok = True
print("빌드 성공!")
#결과
1 번째 빌드 시도
2 번째 빌드 시도
3 번째 빌드 시도
빌드 성공!

(예시라서 3번째에 성공하도록 정해뒀어요.) 지난 글들에서 배운 if문, 비교 연산자, and, not을 while문 조건에 같이 쓸 수 있어요. 배운 개념들이 계속 연결되니까 재밌죠!

# 파이썬 while문 사용법 정리 (for문과 차이, 무한루프 해결, while True + break, 연습문제 정답 포함)

안녕하세요, 하해입니다! ☺️

while문은 **조건이 참(True)인 동안 같은 코드를 계속 반복**하는 문법이에요.
이번 글은 for문과의 차이, 자주 쓰는 패턴, 무한루프 해결법을 정리하고 연습문제 **정답·해설**까지 넣었어요. (파이썬 3.13 기준, 예제는 모두 직접 실행해서 확인했어요)

## 1. 기본 구조

```python
while 조건:
    반복할 코드
```

| 부분 | 의미 |
|---|---|
| `while 조건:` | 조건이 True면 아래 코드를 실행하고, 다시 조건을 확인 |
| 들여쓴 코드 | 조건이 True인 동안 반복 |
| 조건이 False | 반복을 멈추고 while문 다음 줄로 이동 |

## 2. for문과 while문, 언제 뭘 쓸까?

| 구분 | for문 | while문 |
|---|---|---|
| 반복 기준 | 정해진 범위·목록 | 조건이 True인 동안 |
| 잘 맞는 상황 | 반복 횟수를 알 때 | 언제 끝날지 모를 때 |
| 끝나는 시점 | 범위를 다 돌면 자동 종료 | 조건을 직접 False로 만들어야 함 |

## 3. 조건이 바뀌면서 끝나는 패턴

돈이 남아 있는 동안 계속 사는 예제예요. 몇 번 살 수 있는지 미리 몰라도 돼요.

```python
balance = 10000
price = 3000
count = 0
while balance >= price:
    balance -= price
    count += 1
print(f"{count}개 구매, 잔액 {balance}원")
# 결과
# 3개 구매, 잔액 1000원
```

## 4. 원하는 입력이 들어올 때까지 반복

```python
answer = ""
while answer != "yes":
    answer = input("계속하려면 yes 입력: ")
print("시작합니다")
```

실행 예시 (no, yes 를 차례로 입력한 경우)

```
계속하려면 yes 입력: no
계속하려면 yes 입력: yes
시작합니다
```

## 5. while True + break

조건을 `True`로 두면 끝나지 않는 반복이 되고, 안에서 `break`를 만나면 빠져나와요.
"멈출 조건을 반복 중간에 검사"하고 싶을 때 자주 쓰는 패턴이에요.

```python
total = 0
while True:
    n = int(input("숫자 (0이면 종료): "))
    if n == 0:
        break
    total += n
print("합계:", total)
```

실행 예시 (5, 7, 0 을 차례로 입력한 경우)

```
숫자 (0이면 종료): 5
숫자 (0이면 종료): 7
숫자 (0이면 종료): 0
합계: 12
```

`break`와 `continue`의 차이는 지난 글에서 자세히 정리했어요.

## 6. 무한루프가 생기는 이유와 해결

| 원인 | 예시 | 해결 |
|---|---|---|
| 조건에 쓰는 변수를 안 바꿈 | `while i < 5:` 안에서 `i`를 안 바꿈 | 반복 안에서 `i += 1` 처럼 값 변경 |
| 변수를 반대로 바꿈 | `while i < 5:` 안에서 `i -= 1` | 조건이 False에 가까워지는 방향으로 변경 |
| `while True`에 `break`가 없음 | 종료 조건 없음 | 반복 안에 `if 종료조건: break` 추가 |

실행 중인 무한루프는 **Ctrl + C**로 멈출 수 있어요. 터미널에서 실행했다면 `KeyboardInterrupt` 메시지가 나오면서 멈춰요.

## 7. 연습문제

**문제 1.** 1부터 차례로 더해서, 합계가 50을 처음 넘는 순간의 마지막 수와 합계를 출력하세요.

**문제 2.** 1부터 시작해서 2배씩 커지는 수를 1000 미만까지 한 줄로 출력하세요.

**문제 3.** 정수 2026의 각 자리 숫자의 합을 while문으로 구하세요.

## 8. 정답과 해설

**문제 1**

```python
total = 0
n = 0
while total <= 50:
    n += 1
    total += n
print(n, total)
# 결과
# 10 55
```

1부터 9까지 더하면 45라서 아직 50 이하이고, 10을 더한 55에서 처음 50을 넘어요.

**문제 2**

```python
x = 1
while x < 1000:
    print(x, end=" ")
    x *= 2
# 결과
# 1 2 4 8 16 32 64 128 256 512
```

512 다음 값인 1024는 1000 미만이 아니라서 출력되지 않아요.

**문제 3**

```python
num = 2026
digit_sum = 0
while num > 0:
    digit_sum += num % 10
    num //= 10
print(digit_sum)
# 결과
# 10
```

`% 10`으로 마지막 자리를 꺼내고, `// 10`으로 마지막 자리를 지워요. `num`이 0이 되면 반복이 끝나요.

## 요약

| 하고 싶은 것 | 코드 |
|---|---|
| 조건이 맞는 동안 반복 | `while 조건:` |
| 반복 횟수 세기 | 반복 전 `count = 0` → 안에서 `count += 1` |
| 입력이 맞을 때까지 반복 | `while answer != "정답":` |
| 중간에 멈출 조건 검사 | `while True:` + `if 조건: break` |
| 무한루프 멈추기 | Ctrl + C |
