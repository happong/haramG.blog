# 플랫폼별 포맷 가이드

같은 소재라도 플랫폼마다 **제목·구조·본문을 다시 편집**해서 올립니다(말투는 style-guide.md로 통일).
동일한 글을 그대로 복사해 여러 곳에 올리면 원본 판정·검색 노출에서 불리할 수 있습니다.

| 항목 | 네이버 블로그 (메인) | 티스토리 / 구글 블로거 |
|---|---|---|
| 주 유입 | 네이버 검색 | 구글 검색 위주 |
| 제목 | 지역+가게명+핵심 키워드 | 검색 질문형 키워드 (예: "OO 주차 가능한가요") |
| 본문 | 사진 많이, 짧은 문단, 감성 후기 | 소제목(H2/H3) 구조, 정보 정리형, 표·목차 |
| 사진 | 많을수록 유리하다는 통념이 있음(검증 안 됨) | 대표 사진 위주 + 대체텍스트(alt) |
| 맛집 글 적합도 | 높음 | 상대적으로 낮음 — 개발/AI 글 위주 권장 |

※ 위 표는 공식 정책이 아니라 운영 방식 제안입니다. 플랫폼 정책은 각 고객센터 공지를 기준으로 합니다.

## 현재 운영 방침 (2026-10 기준)

- **네이버 블로그**: 메인. 맛집·추천 / 개발 / AI 활용기 전부.
- **티스토리**: 개발 글만.

### 개발 글을 두 곳에 올릴 때 규칙 — "같은 경험, 다른 각도"

코드 예시만 바꾸고 설명 문장을 그대로 두면 그 문단은 유사문서로 판단될 수 있습니다.
(네이버는 문장 단위로 비교한다고 알려져 있고, 정확한 기준은 공개되어 있지 않음)

| | 네이버 | 티스토리 |
|---|---|---|
| 각도 | 공부 과정·막힌 지점·느낀 점 (후기형) | 문제 → 원인 → 해결 코드 → 정리 (레퍼런스형) |
| 제목 | "OO 공부하다 막혔던 후기" | "OO 에러 해결 방법" 같은 검색 질문형 |
| 코드 | 핵심 부분만 짧게 | 실행 가능한 전체 예시 (네이버와 다른 예시) |
| 문장 | 처음부터 새로 작성 | 처음부터 새로 작성 — 같은 문장 재사용 금지 |
