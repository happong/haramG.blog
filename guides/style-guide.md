# 말투 가이드 — 하해

> 근거: 네이버 블로그 글 3편 (사용자가 본문을 직접 붙여넣어 제공, 2026-10)
> - A. 서현역 꽃집 "햇빛꽃집" (봄, 긍정 후기)
> - B. 동탄 "참좋은밥상" 게장 무한리필 (부정 후기)
> - C. 동탄호수공원 피크닉 (가을, 일상·나들이)
> - D. 러너스 클럽 건대점 (러닝화 추천·자세 분석, 정보형 후기)
> - E. 파이썬 for문 (개발 공부, if문 다음 편)
>
> 아래 항목은 모두 위 글에서 실제로 확인된 것만 적었습니다. 괄호 안은 근거가 된 글입니다.

## 1. 인사와 도입

- 첫 줄은 항상 이름 인사: **"안녕하세요, 하해입니다! ☺️"** (B, C) / "안녕하세요. 하해입니다." (A)
- 이어서 **계절·날씨 이야기**로 시작 (A, C)
  - "요즘 날씨가 진짜 너무 좋지 않나요?" (C)
  - "봄이 오고 날씨가 점점 따뜻해지면서, 장롱 속 패딩은 이제 안녕!" (A)
- **독자에게 질문** 던지기: "여러분들은 꽃을 좋아하시나요?", "다들 벚꽃 구경하러 가시나요?" (A)
- 방문 계기를 자연스럽게 연결: "~해서 ~에 다녀왔어요" (A, C)
- 부정 후기는 결론을 먼저: "결론부터 말씀드리면, 5점 만점에 1점 드리고 싶은 곳이었습니다." (B)
- 개인 목표·사연으로 시작하기도 함 — 인사 없이 바로: "올해 새로운 목표를 세웠습니다! 바로 마라톤 하프코스 완주인데요." (D)
- 누구에게 필요한 글인지 밝힘: "마라톤을 목표로 막 달리기를 시작한 러너들에게는 생소할 수 있을 것 같아 후기를 남겨봅니다!" (D)

## 2. 문체

- 기본은 **해요체**, 사이사이 **합니다체**가 섞임
  - "다녀왔어요" / "다시 갔습니다." / "추천드립니다." (C)
- 자주 쓰는 종결: **"~더라고요"**, "~거든요", "~것 같아요", "~잖아요?"
  - 최근 글(B, C)은 "더라고요", A는 "더라구요" → **"더라고요"로 통일**
- 자주 쓰는 강조어: **진짜, 너무, 정말, 딱** (C에 반복 등장)
- 감탄·웃음 표현: "ㅋㅋㅋ", "ㅋㅋㅋㅋ", "ㅎㅎ", "두둥" (A, C) — 부정 후기(B)에는 없음
- 속마음을 따옴표로: "아... 반차 쓰길 잘했다." 라는 생각이 들더라고요. (C)
- 꾸미는 표현에 "이쁘다"를 자주 사용 (A)

## 3. 이모지

- 일상·긍정 글(C): 소제목 앞에 이모지 + 문장 끝 ☺️ 😂 자주 사용
  - 소제목 예: "🌳 파란 하늘, 호수 그리고 넓은 들판", "🍜 회 먹다가 갑자기 라면"
  - 목록도 이모지로: "🍺 하이트제로 / 🍶 소주 / 🍷 레드와인 / 🥂 화이트와인"
- 부정 후기(B): 인사의 ☺️ 외에는 이모지 없음 → **글 분위기에 따라 이모지 양 조절**
- 정보형 후기(D): 체크 기호로 정리 — "📍 방문 전 필수 체크!", "✔️ 예약 필수!", "✅ 1. 발 모양 & 걸음걸이 분석", "➡️ 교정 방법: …", "💰", "🎯 총평"

## 4. 문단·줄바꿈

- **한 줄에 한두 문장**, 짧게 끊어 씀 (C)
- 문단 사이에 빈 줄을 많이 둠 (A, B, C)

## 5. 글 구조

### 맛집·장소 후기 (A, B)
1. 인사 + 계절/방문 계기
2. **위치** — 지도 + 주소, 찾아가는 길 상세 설명
   - "서현역 로데오거리에서 JARA 건물이 있는 쪽으로 나오면 … 문을 열고 들어가면 바로 매장이 위치해 있습니다." (A)
3. **운영시간** (A)
4. **분위기** / 항목별 **후기** — 부정 후기는 "위생 / 맛 / 가성비 / 총평"처럼 항목을 나눔 (B)
5. **구체적 수치**: 가격·시간 ("15,000원 정도", "둘이 합쳐 6만 원 가까이", "채 10분이 걸리지 않았어요") (A, B)
6. 추천 대상 / 재방문 의사 + 팁 ("미리 전화해서 주문도 가능") (A, B)
7. 마무리 인사

### 정보형 후기 (D)
1. 개인 목표·계기
2. 📍 방문 전 체크 (지점, 예약 여부)
3. 받은 서비스 단계별 정리 (✅ 1. / ✅ 2.)와 직접 느낀 점
4. 💰 구매 방법 — 매장 대신 온라인 구매한 이유까지
5. 🎯 총평: ✅ 추천 대상 목록 → 📌 한 줄 요약 → ⭐️ 평점 (예: 4.8/5.0)
6. 관련 글 연결: "자세한 후기는 아래 글을 참고해주세요.", "(무릎 보호대 후기는 따로 작성 예정!)"

### 일상·나들이 (C)
- 시간 순서대로 장면마다 이모지 소제목
- 마지막에 하루를 한 줄로 요약: "맛있는 음식 챙겨가고, 중간에 산책도 하고, 배부르면 낮잠도 자고, 공연도 보고, 저녁에는 와인 한잔까지!"

### 개발 공부 (E)
1. 인사 "안녕하세요! 하해입니다." + **지난 글 연결**: "지난 글에서 if문으로 … 배웠다면, 오늘 배울 for문은 …"
2. 개념 한 줄 정의 ("for문은 '정해진 범위 안에서 같은 동작을 반복해라'는 명령이에요.")
3. **게임 PM 업무 비유**: 빌드 서버 상태 체크, 에러 로그, 빌드 결과, QA/Dev/Art 팀
4. 코드 + `#결과` 주석으로 출력 보여주기
5. 헷갈리는 점 강조: "중요한 점 하나! … 꼭 기억해주세요!"
6. 자주 하는 실수 (콜론 빠뜨림 → SyntaxError)
7. "실무에서 이렇게 쓰여요" — 앞에서 배운 문법과 합쳐서 쓰는 예시
8. **퀴즈 4문제**: 코드 읽기 / 빈칸 채우기 / 코드 고치기 / 출력 결과 맞추기 → "정답은..! 모두 직접 실행을 한 번 해보시죠!"
9. 마무리 + **다음 편 예고**: "다음엔 반복을 중간에 멈추는 break와 건너뛰는 continue도 다뤄볼게요!"
- 해시태그에 독자층이 드러남: #비전공자코딩 #직장인코딩 #직무전환 #PM #커리어전환

## 6. 솔직함과 균형

- 직접 겪은 사실만 씀: "이 후기는 제가 직접 방문하고 느낀 개인적인 경험을 바탕으로 작성한 글이에요, 참고용으로만 봐주시면 좋겠습니다!" (B)
- 나쁜 점을 쓸 때도 좋은 점은 인정함: "다만 게 자체는 아예 별로였다고는 못 하겠어요." / 가성비 항목은 긍정적으로 (B)
- 블로그 목적을 직접 밝힘: "솔직한 정보 공유가 이 블로그의 목적이니까" (B)
- 독자를 위한 실용 팁: "그늘 자리 잡으려고 하시는 분들은 조금 일찍 가시는 게 좋을 것 같아요!" (C)

## 7. 마무리

- 추천이나 권유로 끝냄
  - "만약, 서현에서 꽃집을 찾으신다면 추천드립니다!" (A)
  - "위생에 예민하신 분들이라면 방문 전에 한 번 더 고민해보시는 걸 추천드려요." (B)
- 독자에게 말 걸기: "다들 사랑하는 사람에게 꽃 선물을 하고 이쁜 하루를 보내보세요!" (A)
- **해시태그 뒤에 독자와 소통하는 한 줄** (의도된 스타일): "편하실 때 코드 실행해보시고, 퀴즈 정답 확인 필요하시면 말씀해주세요!" (E)
  - 댓글로 질문이나 대화를 유도하는 용도. 개발 글, 특히 퀴즈가 있는 글에 넣음

## 8. 해시태그

- **정확히 30개** 씀 (하해님 요청). 참고: 기존 글은 A 30개, B 20개, C 30개, D 29개, E 30개 (네이버의 "+N" 표시 기준으로 셈)
- 구성: 지역+업종 (#동탄맛집, #서현역꽃집), 가게·장소명, 가게명+후기, 메뉴/물건, 성격 (#내돈내산후기, #동탄솔직후기), 계절 (#가을피크닉)
- 개발 글: 언어 (#Python #파이썬), 문법 (#for문 #range), 수준 (#파이썬기초 #코딩입문), 독자층 (#비전공자코딩 #직장인코딩)

## 9. 초안 작성 시 지킬 것

- 경험 메모에 없는 맛·서비스·분위기는 쓰지 않음
- 원문에 있던 오타는 따라 하지 않음 (예: A의 "됩답니다")
- 개발 글의 코드는 발행 전에 실제로 실행해서 결과를 확인
- **개발 용어는 정확하게**: 문법 설명에서 용어를 섞어 쓰지 않음
  - 예: for문 첫 줄을 "조건"이라고 부르지 않음 → "for문도 첫 줄 끝에 콜론(:)을 붙이고" (if문은 조건, for문은 반복할 대상)
- 사람·장소를 부르는 표현은 사용자 메모의 표현을 그대로 따르고, 임의로 바꾸거나 통일하지 않음
- 가게 정보(주소, 운영시간, 가격)는 메모나 직접 확인한 내용만 사용하고, 바뀔 수 있으니 발행 전에 다시 확인
